Filius

Le simulateur de réseaux, directement dans le navigateur.

Le premier lancement peut prendre jusqu’à une minute, le temps de charger Java dans le navigateur.

Pour garder votre travail, cliquez sur la disquette dans Filius : le fichier .fls arrive dans votre dossier Téléchargements.

Filius est un logiciel libre (GPL) créé par Stefan Freischlad : lernsoftware-filius.de. Il fonctionne ici grâce à CheerpJ.

Filius est fermé.

Les réseaux non enregistrés sont perdus.
